## 📖 Overview

A modern web application designed to classify user-generated content as **Toxic** or **Safe**. It features a sleek dark-teal interface with real-time analysis for both text and images. 

Simply type a message or upload an image, and the AI will instantly evaluate its safety.

## ✨ Features

- **Text Analysis:** Enter any text to instantly detect toxic language.
- **Image Analysis:** Upload an image. The AI generates a caption and then analyzes it for toxicity.
